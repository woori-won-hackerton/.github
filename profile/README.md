## 👋 About Us

안녕하세요! 저희는 **2026 우리WON 청년 IT 아카데미 금융 AX 해커톤**에 참여한 WONmate 팀입니다.

금융 현장의 불편함을 기술로 해결하고자 모였으며, 신입 보험설계사(FC)의 상담 업무를 지원하는 AI 기반 서비스 **WONmate**를 개발했습니다.
